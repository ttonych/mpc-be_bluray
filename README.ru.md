# mpc-be_bluray

[English](README.md)

**Поддержка меню Blu-ray в MPC-BE, адаптированная для работы с видеорендерером madVR.**
Проект добавляет поддержку меню HDMV и BD-J через libbluray. Это позволяет
пользоваться меню Blu-ray и смотреть фильмы в MPC-BE с выводом через
видеорендерер madVR.

Тестирование проводилось с **madVR 210 x64**.

Это независимый экспериментальный форк. Текущая основа — официальный релиз
**MPC-BE 1.9.1**, **libbluray 1.5.0** и два сопровождаемых локальных патча.
Версия форка: **1.9.1-bluray.1**.

## Скачать и начать просмотр

Скачать [1.9.1-bluray.1 — ZIP для Windows x64](https://github.com/ttonych/mpc-be_bluray/releases/download/1.9.1-bluray.1/mpc-be_bluray-1.9.1-bluray.1-x64.zip).
Это предварительный выпуск; [результаты проверки](https://github.com/ttonych/mpc-be_bluray/releases/tag/1.9.1-bluray.1) указаны в его описании.
Портативный комплект содержит русский и английский интерфейсы. Java и madVR
устанавливаются отдельно.
Инструкции без интернета: откройте `Readme.ru.html` или `Readme.html` из распакованного ZIP.

1. Распакуйте тестовый ZIP в отдельную папку, доступную для записи.
2. Запустите `mpc-be64.exe`. Выберите копирование настроек существующего MPC-BE
   или стандартные настройки. Перед копированием закройте исходный плеер.
3. **Если madVR уже установлен, ничего устанавливать или обновлять не нужно.**
   Если madVR ещё нет, установите [основной комплект](https://madshi.net/madVR.zip),
   затем распакуйте [обновление 210](http://madshi.net/madVRhdrMeasure210.zip)
   поверх него в ту же папку madVR с заменой файлов.
   В настройках видеовывода MPC-BE должен быть выбран **madVR**.
   [Подробный порядок установки](docs/ru/USAGE.md#установка-и-madvr).
   Графика меню реализована через madVR; поддержка меню с другими
   видеорендерерами в текущей версии не предусмотрена.
4. Для BD-J установите проверенную **Eclipse Temurin JRE 21.0.12.1+1, Windows x64,
   HotSpot** и укажите её папку на вкладке **Blu-ray → Java и данные**.
   [Инструкция и официальная загрузка Java](docs/ru/USAGE.md#java-для-bd-j).
   Для обычных меню HDMV Java не нужна.
5. Откройте диск целиком или файл `BDMV\index.bdmv`. Открытие отдельного `.mpls`
   запускает этот плейлист без навигации по меню диска.

В меню работают стрелки и **Enter**; **Alt+T** вызывает главное меню,
**Alt+R** — всплывающее. Для некоторых дисков также доступно управление мышью.
Доступность команд и поддержка мыши зависят от реализации меню диска.

## Что добавлено

- Навигация HDMV и BD-J с выводом графики меню через madVR.
- Управление клавиатурой и мышью, если её поддерживает меню диска.
- Неподвижные изображения, авторская графика загрузки, выбор звука и субтитров
  через меню диска, переходы по главам средствами MPC-BE.
- Настройки Blu-ray: регион, языки, Java, данные дисков и совместимость.
- Понятный список сохранённых дисков с переименованием и сбросом данных одного диска.
- Отдельный профиль портативной тестовой версии с импортом настроек существующего MPC-BE.

## Если MPC-BE уже установлен

Храните тестовую сборку в отдельной папке. Она использует собственный
`mpc-be64.ini`, даже если при первом запуске его ещё нет. Импорт читает выбранный
исходный профиль и не изменяет его. Сохранения дисков и история не импортируются.

У madVR и других внешних фильтров собственные настройки, которые могут быть общими
для нескольких плееров. Изоляция профиля не создаёт отдельную установку madVR.
Подробнее: [импорт настроек и обновление](docs/ru/USAGE.md#существующие-настройки-и-обновление).

## Текущие ограничения

Разработка и проверки воспроизведения ориентированы на связку **MPC-BE + madVR**.
Работа каждого диска и каждой версии madVR не гарантируется.

- При смене плейлиста возможна пауза из-за пересоздания графа воспроизведения.
- BD-Live, воспроизведение «картинка в картинке» и звуки кнопок меню не реализованы.
- Некоторые меню BD-J работают только с клавиатуры. Управление расположением видео
  из Java и полная синхронизация паузы с Java не реализованы.
- На 3D-дисках проверены меню и запуск; полноценный MVC/стереовывод не проверен.
  Исправления HDR-меню не подтверждают точность HDR-видеовывода.
- Средства расшифровки дисков не входят в комплект; содержимое диска должно читаться.

Локальная сборка на официальной базе 1.9.1 проверена на **Baby Boom (HDMV)**
и **Ford v Ferrari (BD-J)**. Каждый облачный кандидат проверяется отдельно;
результаты для конкретного ZIP указываются в описании его выпуска.
