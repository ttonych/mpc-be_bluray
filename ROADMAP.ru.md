# План развития

[English](ROADMAP.md) · [О проекте](README.ru.md) · [История изменений](docs/ru/CHANGELOG.md)

Проект адаптирует меню Blu-ray в MPC-BE для работы с **видеорендерером madVR**.
Первая предварительная portable-сборка Windows x64 [уже опубликована](https://github.com/ttonych/mpc-be_bluray/releases/tag/1.9.1-bluray.1);
её можно пробовать рядом с обычным MPC-BE. Приоритеты могут меняться
по отзывам; перечисленные задачи не обещают сроков или полной совместимости.

## Текущее состояние

- [x] Интеграция перенесена на официальный релиз MPC-BE 1.9.1.
- [x] Локально собраны MPC-BE, русские ресурсы, libbluray 1.5.0 и два её JAR
  с применением обоих сопровождаемых патчей.
- [x] Выполнены компонентные тесты, проверки локальных патчей и сканера публикации.
- [x] На локальной базе 1.9.1 проверены HDMV на Baby Boom и BD-J на Ford v Ferrari.
- [x] Подготовлены отдельный портативный профиль и импорт существующих настроек.
- [x] Подготовлены RU/EN-документация и конфигурация ручной сборки GitHub.

Исходники опубликованы, защита `main` включена.
[Первая облачная сборка](https://github.com/ttonych/mpc-be_bluray/actions/runs/35601595821)

кандидат с оформлением форка прошёл пользовательскую проверку на «Истории рыцаря»
(BD-J) и Baby Boom (HDMV). Grand Prix выявил отсутствие отдельно записанной музыки
меню и падение при повторном чтении после отказа. Исправления включены
в облачный кандидат 35619821494. Проверки пакета и профиля RU/EN прошли;
пользователь подтвердил работу трёх дисков. Тот же ZIP опубликован
как предварительный выпуск 1.9.1-bluray.1.

  и результатам тестов.

## Отложено или не запланировано

| Направление | Статус |
| --- | --- |
| Локальный диагностический отчёт и ссылка на обращения проекта | Отложено до следующей рабочей сессии; настройка обработчика ошибок madVR требует отдельного исследования |
| Бесшовные переходы между плейлистами | Сознательно отложены; ограничение остаётся до возвращения к этой задаче |
| Штатный профиль / установщик | Вернуться после портативного тестирования; существующий вариант сборки сохранить |
| BD-Live, PiP, звуки кнопок, расположение видео из Java и полная синхронизация паузы | Известные пробелы; для каждого нужны отдельный объём работ и проверки |
| Полноценный MVC/стереовывод и расширенная проверка HDR | Меню и запуск этого не подтверждают; готовность не заявляется |
| Другие видеорендереры или перенос в MPC-HC | Вне текущего выпуска MPC-BE, ориентированного на madVR |
| Java 25+ | Переход не обещается при текущей несовместимости BD-J с SecurityManager |

Завершённые изменения записываются в историю изменений. Этот файл и английская
версия обновляются вместе при изменении приоритетов и подтверждённых результатов.
