# Локальные патчи libbluray 1.5.0

[English](README.en.md) · [Сопровождение проекта](../../docs/ru/DEVELOPMENT.md)

Команды ниже выполняются из корня репозитория `mpc-be_bluray`.
Перед первой проверкой выполните [полную локальную сборку](../../docs/ru/DEVELOPMENT.md#локальная-сборка):
для последующей сборки плеера нужны и нативная DLL, и оба JAR.

## Навигация: playmark-seek-v1 (22.09.2026)

После перехода исходный код пропускал метки, расположенные ровно на следующем
пакете для чтения. Несколько меток могут попадать в один пакет из-за привязки
к одной точке произвольного доступа. Меню BD-J, ожидающее такую метку, могло
оставаться на фоновом ролике после возврата из фильма.

Патч включает позицию перехода в поиск следующей метки. События по-прежнему
поступают только после чтения этого пакета, по одному на метку до следующего
перехода. Меняется нативный `bluray.c`; условий для конкретного диска нет,
JAR и отрисовка не меняются. На проверенном UHD BD-J-диске пользователь
подтвердил работу смены языка меню и возврата из фильма. В журнале пяти
возвратов обе метки поступили, после чего снова появилась графика меню.

Нативная сборка применяет `mouse-page-v1`, затем `playmark-seek-v1`: оба меняют
`bluray.c`. По точным хешам проверяется целиком исходное, промежуточное или
конечное состояние. Неожиданные изменения останавливают сборку.

```powershell
python bluray/tools/libbluray-local-patch.py --component native
python bluray/tools/test-libbluray-local-patch.py --component native
python bluray/tools/test-playmark-seek.py
```

Синтетический тест компилирует настоящие функции обработки меток и проверяет
совпадение позиций, несколько меток на одной точке доступа, однократную выдачу,
переход назад, пропущенные метки, пустой список и большие смещения. Исходный
код этот тест не проходит. Отдельный нативный тест на диске также подтвердил
потерю меток и исправленную выдачу; это не проверка полной совместимости диска.

При осознанном сопровождении экспортируйте компонент с `--component playmark-seek
--export --base-source <исходники-с-mouse-page-v1>`. Указанная основа должна
совпадать с хешами mouse-патча. Mouse-патч сопровождайте в отдельной копии
исходников до применения патча меток; не объединяйте их случайно экспортом
общего дерева как `mouse-page`. Патч не отправлен и не принят в upstream VideoLAN.

## BD-J: bdj-toggle-v1 (20.09.2026)

`libbluray-1.5.0-bdj-toggle.patch` исправляет активацию HAVi-кнопок.
В исходной 1.5.0 Enter вызывал обработчик `HActionableHelper` напрямую,
минуя виртуальный `processHActionEvent` компонента. Кроме того, у
`HToggleButton` отсутствовала обработка переключения состояния при действии.
На Double Jeopardy (Remastered) Settings открывался, но его кнопка оставалась
выключенной. При возврате фокуса на Play код диска проверял это состояние
и не закрывал панель. Затем Settings и Scenes накладывались друг на друга.

Enter теперь направляет событие компоненту; `HToggleButton` меняет состояние
до уведомления слушателей, учитывает группу и принудительный выбор.
Отключённая кнопка не активируется; при выключении используется unset sound.
Обычные графические и текстовые кнопки сохраняют одно уведомление на Enter.
Названия дисков, координаты и классы конкретного Xlet в патче отсутствуют.
Изменены два Java-файла, нативная DLL и MPC-BE для этого исправления не менялись.

`bluray/tools/build-bdj.ps1` строго проверяет/применяет этот патч перед сборкой JAR.
Отдельный JSON хранит базовые/конечные хеши и хеш патча. Для повторной проверки
и сборки существующего патча:

```powershell
python bluray/tools/test-libbluray-local-patch.py --component bdj-toggle
./bluray/tools/build-bdj.ps1 -JavaHome 'C:\Java\jdk-21'
./bluray/tools/test-bdj-toggle.ps1 -JavaHome 'C:\Java\jdk-21'
./bluray/tools/build-player.ps1
```

Только при намеренном изменении Java-патча после проверки правок в исходниках
выполните экспорт:

```powershell
python bluray/tools/libbluray-local-patch.py --component bdj-toggle --export
```

Команда перезаписывает патч и его манифест. Проверьте получившийся diff и затем
повторите проверки и сборку выше. Экспорт не нужен для обычной сборки и не должен
использоваться для обхода неожиданной ошибки хешей.

Тест использует реальные HAVi-классы из собранного JAR; заменены только
JNI-логгер и выбор оформления из контекста Xlet, чтобы запускать тест без
диска/окна. Проверяются вызов переопределённого метода, порядок состояния и
слушателя, повторное нажатие, отпускание, звуки, disabled и группы.
На исходном JAR тест падает, на исправленном проходит. Живая проверка:
Settings → выбор субтитров → Play; Scenes → вниз → главное меню.

Проверка звуковых событий подтверждает логику HAVi; воспроизведение звуков
кнопок в интеграции плеера пока не реализовано.

Патч локальный, не отправлен и не принят в upstream. Лицензия LGPL сохранена.
При обновлении libbluray нужно проверить, исправлена ли причина upstream,
а затем перенести или удалить патч и повторить проверки.

## HDMV: mouse-page-v1

Локальное расширение для интеграции меню MPC-BE, адаптированной под madVR, 19.09.2026.
Патч не отправлен и не принят в upstream VideoLAN.

### Причина

На BABY BOOM нижняя навигация нарисована в видео. Страница выбора глав
содержит невидимую auto-action кнопку, единственная команда которой —
`SetButtonPage` обратно в основную навигацию. Стрелка вниз достигает её,
а `bd_mouse_select` проверяет только кнопки с selected-графикой текущей
страницы. Поэтому клик по нижнему меню из подменю даёт 0.

### Изменение

Добавлена функция `bd_mouse_select_page` и внутреннее сообщение контроллера.
Существующие функции и их поведение сохранены. MPC-BE вызывает расширение
только для клика, который не попал в активную кнопку. Функция рассматривает
только включённые невидимые auto-action кнопки с одной безусловной командой
`SetButtonPage` и непосредственными операндами. Нужна ссылка из включённой
выбираемой кнопки и выбираемая кнопка под курсором на целевой странице.
Неоднозначные переходы, эффекты, маски ввода и сложные скрипты отклоняются.

Команда выполняется обычной HDMV VM через `bd_read_ext(..., len=0)`. После
возврата плеер повторяет hit-test и только затем активирует выбранный пункт.
Координаты BABY BOOM присутствуют только в тестовом сценарии. Плеер и DLL
получают геометрию и команды из данных диска.

Это ограниченная совместимость с определённым способом авторинга меню.
Произвольные диски и BD-J данным расширением не покрываются. Наведение по
нижним пунктам из подменю не переключает страницу: переход выполняет клик.

### Воспроизведение и сопровождение

`bluray/tools/build-libbluray.ps1` проверяет SHA-256 архива VideoLAN и вызывает
`bluray/tools/libbluray-local-patch.py`. Патч и JSON-манифест хранят исходные и
конечные SHA-256 четырёх изменённых файлов. Повторная сборка идемпотентна;
неожиданные изменения или другая версия исходников останавливают сборку.
`--export` предназначен для сопровождающего после осознанного редактирования
этих четырёх файлов; обычная сборка его не вызывает.

Повторная проверка после полной локальной сборки. Для сценариев с диском
смонтируйте Baby Boom в `V:` либо укажите его путь в `-Disc`:

```powershell
python bluray/tools/test-libbluray-local-patch.py
./bluray/tools/build-libbluray.ps1 -DependencyRoot "$PWD/bluray/build/vcpkg_installed/x64-windows"
./bluray/tools/test-mouse-submenus.ps1 -Disc 'V:\'
./bluray/tools/test-hdmv.ps1 -Disc 'V:\'
./bluray/tools/test-menu-coordinates.ps1
./bluray/tools/build-player.ps1
```

Тест подменю проверяет графические результаты переходов между главами,
SET UP и SPECIAL FEATURES, пустые области, обе стрелки перелистывания и
запуск фильма только по PLAY MOVIE. Это компонентная проверка libbluray;
реальные клики в окне и madVR проверяются отдельно.

При переходе на новую upstream-версию: сравнить изменённые функции, перенести
патч, обновить закреплённую версию/хеши, собрать DLL и повторить компонентные
и живые проверки. Тихое применение со смещением или подмена новой DLL
без проверки не допускаются сборочным скриптом. Это требует ручной работы;
автоматическая совместимость с будущими версиями не гарантирована.

Перед публикацией upstream стоит обсудить саму семантику fallback и добавить
проверки на других дисках. Изменённые исходники сохраняют лицензию LGPL
libbluray; патч должен поставляться вместе с локальной DLL.
