# История изменений форка

[English](../en/CHANGELOG.md) · [О проекте](../../README.ru.md)

Здесь описываются изменения нашего форка. История оригинального MPC-BE сохранена
в [Changelog.Rus.txt](../Changelog.Rus.txt).

## 1.9.1-bluray.1

Основа: официальный MPC-BE 1.9.1; libbluray 1.5.0 с локальными патчами
`mouse-page-v1` и `bdj-toggle-v1`. Статус публикации и результаты проверки ZIP
указываются в описании выпуска.

- Добавлена навигация по меню HDMV и BD-J, адаптированная для работы с видеорендерером madVR.
- Добавлены команды меню, выбор дорожек диска, отметки глав и OSD.
- Исправлены координаты мыши при чёрных полях; добавлен ограниченный переход
  из HDMV-подменю для совместимых способов авторинга.
- Добавлены стартовая графика меню и неподвижные изображения; улучшены время
  показа галерей, проверка RLE, управление временем жизни графики и яркость HDR-меню.
- Добавлены обнаружение смены диска, обновление его названия и скрытие отметок
  глав в меню и фоновом воспроизведении.
- Добавлены вкладки настроек Blu-ray и понятный список данных дисков со сбросом
  и переименованием.
- Добавлена настройка внешней Java; проверена Temurin JRE 21.0.12.1+1 x64.
- Добавлены отдельный портативный профиль и импорт настроек, русские и английские ресурсы.
- Номер форка отображается в заголовке, «О программе» и свойствах EXE; проверка
  обновлений обращается к этому форку, включая опубликованные предварительные выпуски.
- В ZIP добавлены русские и английские HTML-инструкции для чтения без интернета.
- Добавлены сопровождаемые патчи libbluray, компонентные тесты, проверки публикации,
  конфигурация ручной сборки GitHub Actions и двуязычная документация.

Проверенный видеорендерер — madVR 210 x64: обновление 210 поверх основного
комплекта madVR. Порядок установки и обе ссылки приведены в [руководстве](USAGE.md#установка-и-madvr).

На официальной базе 1.9.1 локально проверены Baby Boom (HDMV) и Ford v Ferrari
(BD-J). Ранее в разработке выборочно проверялись меню, неподвижные изображения
и навигация других BD/UHD/3D-дисков; это не полный повтор проверки на новой основе.
Первая сборка GitHub Actions прошла компиляцию, компонентные тесты и проверку
целостности пакета. Проверка воспроизведения относится к конкретному ZIP;
её результаты приводятся в описании выпуска.

Бесшовные переходы между плейлистами, BD-Live, воспроизведение PiP и полноценная
проверка стереовывода не входят в завершённую работу этого выпуска. Подробнее:
[текущие ограничения](../../README.ru.md#текущие-ограничения).
