# Руководство пользователя

[English](../en/USAGE.md) · [О проекте](../../README.ru.md)

## Установка и madVR

Интеграция меню Blu-ray адаптирована для работы MPC-BE с **видеорендерером madVR**.
Распакуйте тестовую сборку Windows x64 в отдельную папку, доступную для записи.
Тестирование проводилось с **madVR 210 x64**.

**Если madVR уже установлен, ничего устанавливать или обновлять не нужно.**

**Если madVR ещё нет**, установите его в два этапа:

1. Установите [основной комплект madVR](https://madshi.net/madVR.zip).
2. Скачайте [madVR 210](http://madshi.net/madVRhdrMeasure210.zip) и распакуйте
   содержимое архива в ту же папку madVR, подтвердив замену файлов.

В настройках видеовывода MPC-BE должен быть выбран **madVR**.

Порядок обновления поверх основного комплекта также указан
[разработчиком madVR](https://bugs.madshi.net/view.php?id=706).
Текущая реализация графики меню использует madVR; другие видеорендереры для
меню не поддерживаются. Сам madVR и Java runtime в ZIP плеера не входят.

Откройте **Вид → Настройки → Воспроизведение → Blu-ray** и включите меню Blu-ray.
Откройте диск целиком или `BDMV\index.bdmv`. Для воспроизведения одного плейлиста
без навигации по меню откройте его `.mpls`. Средства расшифровки дисков не включены.

## Java для BD-J

HDMV работает без Java. Для BD-J нужна полноценная Java x64 с графическими
компонентами AWT. Проверенная версия — **Eclipse Temurin JRE 21.0.12.1+1,
Windows x64, HotSpot**. Для просмотра JDK не требуется.

- [Официальный выпуск](https://github.com/adoptium/temurin21-binaries/releases/tag/jdk-21.0.12.1%2B1).
- [ZIP JRE для Windows x64](https://github.com/adoptium/temurin21-binaries/releases/download/jdk-21.0.12.1%2B1/OpenJDK21U-jre_x64_windows_hotspot_21.0.12.1_1.zip).
- [SHA-256 от разработчика](https://github.com/adoptium/temurin21-binaries/releases/download/jdk-21.0.12.1%2B1/OpenJDK21U-jre_x64_windows_hotspot_21.0.12.1_1.zip.sha256.txt).

Распакуйте Java и укажите её корневую папку в **Blu-ray → Java и данные →
Java (x64)**. Внутри должен находиться `bin\server\jvm.dll` (либо
`jre\bin\server\jvm.dll` для соответствующей структуры runtime).
Нажмите **Применить / ОК** и заново откройте диск. После замены Java полностью
перезапустите MPC-BE. При явно заданном пути установка Java в систему и изменение
`JAVA_HOME` не нужны.

Пустой путь включает автоматический поиск при открытии диска. Страница настроек
проверяет наличие файлов; это ещё не подтверждает работу BD-J с выбранной JVM.
Оба JAR libbluray должны оставаться рядом с плеером.

В проверках проекта Java 25 завершилась ошибкой `Failed initializing SecurityManager`.
Используйте проверенную Java 21: более новая основная версия не обязательно совместима.
[Oracle сообщает об отключении Security Manager начиная с Java 24](https://docs.oracle.com/en/java/javase/24/security/security-manager-is-permanently-disabled.html).
Новые обновления ветки Java 21 нужно проверить перед сменой рекомендуемой версии.

## Управление

Ниже приведены стандартные клавиши. Если вы изменяли сочетания в MPC-BE, они могут отличаться.

| Действие | Управление |
| --- | --- |
| Перемещение и выбор в меню | Стрелки, Enter |
| Главное меню | Alt+T; Home в режиме навигации меню |
| Всплывающее меню во время фильма | Alt+R |
| Закрыть всплывающее меню | Escape, если это предусмотрено диском |
| Следующая глава / пропуск вступительного ролика | Page Down или кнопка перехода вперёд |
| Начало текущей / предыдущая глава | Page Up или кнопка перехода назад |
| Перемотка при закрытом меню | Влево / вправо |
| Громкость при закрытом меню | Вверх / вниз |

Диск может запрещать пропуск или вызов меню в определённый момент. При запрете
пропуска MPC-BE показывает сообщение. Если следующей главы нет, разрешённый
пропуск завершает ролик и передаёт управление сценарию диска. Переход назад
возвращает к началу текущей главы; в её первые три секунды — к предыдущей.
При видимом меню команды глав отключены.

Работа мыши зависит от того, как создано меню, особенно в BD-J. Если диск не
обрабатывает мышь, используйте клавиатуру. Отметки глав скрываются в меню и
фоновых циклах, а во время фильма показываются. OSD глав использует настройку
показа времени перемотки MPC-BE; меню BD-J может дополнительно рисовать своё уведомление.

## Настройки Blu-ray

| Вкладка | Назначение |
| --- | --- |
| Меню диска | Регион A/B/C, страна, языки меню/звука/субтитров, возраст зрителя, предпочтение 2D/3D |
| Java и данные | Папка Java, запоминание настроек и прогресса, папки данных и кэша, список дисков |
| Совместимость | Возможности, сообщаемые меню диска, с описаниями и техническими значениями |

Языки и страну можно выбрать из списка или ввести код: например, `rus`/`eng`
и `RU`/`US`. Диск может продолжить использовать сохранённый им язык. Регион —
значение региона плеера, сообщаемое диску. Параметры совместимости описывают
возможности: они не устанавливают декодеры, не настраивают madVR и не добавляют
нереализованные функции PiP/3D.

На вкладке «Совместимость» двойной щелчок по значению или **Enter / F2** открывает
редактор. Enter подтверждает изменение, Escape отменяет. Поиск не учитывает
регистр. Сброс параметра убирает ручное переопределение. Числовые маски принимают
десятичное число или `0x…`. Изменения, сохранённые через **Применить / ОК**,
действуют при следующем открытии диска. Выбор другой папки данных не переносит
существующие файлы автоматически.

## Настройки и прогресс дисков

В **Java и данные → Список дисков…** можно найти, переименовать и сбросить
сохранённый диск, а также открыть папку его данных. «Последнее открытие» — время
открытия диска, а не последней записи прогресса его Java-приложением. Сохранениями
управляет приложение диска; продолжение просмотра предусмотрено не на каждом диске.

По умолчанию данные находятся в `bdj-data` рядом с `mpc-be64.exe`:

| Папка | Содержимое |
| --- | --- |
| `catalog` | Названия, пользовательские подписи и сведения об открытии |
| `persistent` | Общие постоянные данные BD-J |
| `cache` | Временные данные приложений дисков |
| `discs/<id>/<поколение>/persistent` | Отдельное хранилище после сброса диска |

Внутри persistent файлы группируются по идентификаторам организации и
Java-приложения. Это пространства имён, а не обязательно отдельные фильмы:
несколько дисков могут использовать общие данные.

**Сбросить данные…** запрашивает подтверждение и сразу выбирает пустое хранилище
для следующего открытия диска. Старые файлы сохраняются; другие диски и текущая
сессия воспроизведения не меняются. Отмена основного окна настроек не отменяет
сброс. Для старой общей записи без надёжного ID диска сброс недоступен.
При пользовательском корне используется `mpc-be-discs/<id>/<поколение>`;
каталог и маркер сброса остаются рядом с плеером.

## Существующие настройки и обновление

Экспериментальная портативная сборка всегда использует `mpc-be64.ini` рядом с EXE.
Если INI отсутствует, она не переключается на профиль установленного MPC-BE
в реестре. При первом запуске доступны четыре варианта:

| Источник | Что проверяется |
| --- | --- |
| Реестр | `HKCU\Software\MPC-BE` текущего пользователя |
| Найденный INI | `%APPDATA%\MPC-BE\mpc-be64.ini`, затем `mpc-be.ini` |
| Указать INI вручную | Файл настроек из другой портативной папки MPC-BE |
| Стандартные настройки | Новый профиль без импорта предпочтений другого плеера |

Наличие реестра и найденного INI показано независимо, вместе с их расположением.
Перед импортом закройте исходный плеер. Копируются обычные настройки и файлы
шейдеров; история, плейлисты и сохранения BD-J не переносятся. Пути хранилищ BD-J
из исходного профиля сбрасываются, чтобы тестовые данные были отдельно. Исходный
профиль не меняется. Существующий тестовый профиль сохраняется без повторного импорта.

История, веб-сервер, WinLIRC и глобальные медиаклавиши изначально выключены.
Ассоциации файлов и интеграция с Проводником в тестовом режиме недоступны.
Если папка недоступна для записи, запуск прекращается без перехода к общему профилю.

Внешние фильтры должны оставаться доступными. Относительные пути к их DLL при
импорте привязываются к папке исходного плеера — сохраните её, если там находятся
фильтры. У madVR и других фильтров свои настройки, которые могут быть общими;
изменение этих настроек может повлиять и на другие плееры.

Проверка обновлений обращается к выпускам **MPC-BE Blu-ray**, включая
опубликованные предварительные версии, а не к оригинальному MPC-BE.
Она открывает страницу выпуска; файлы не устанавливаются и не заменяются автоматически.

Перед обновлением закройте тестовый плеер и сохраните копию INI и данных дисков,
включая пользовательские папки хранения. Распакуйте новый комплект отдельно и,
прочитав указания к выпуску, заменяйте только программные файлы. Не перезаписывайте
рабочий INI чистым INI из нового ZIP.

## Решение проблем и обратная связь

| Проблема | Что проверить сначала |
| --- | --- |
| Видео есть, графики меню нет | Выберите madVR, включите меню Blu-ray, откройте диск/index вместо плейлиста |
| BD-J не запускается | Проверьте Java 21 x64, её корневую папку и оба JAR libbluray; после замены Java перезапустите плеер |
| Мышь не работает в меню | Попробуйте стрелки и Enter: некоторые диски поддерживают только клавиатуру |
| Нельзя пропустить вступление | На диске может быть запрет; прочитайте сообщение OSD |
| CRC или ошибка чтения диска | Проверьте чтение вне MPC-BE, при необходимости перемонтируйте и заново откройте диск |
| Старый язык или предложение продолжить | Проверьте список дисков и при желании сбросьте данные этого диска |
| Пауза между плейлистами | Это известное ограничение текущей интеграции воспроизведения |

Перед сообщением об ошибке посмотрите [текущие ограничения](../../README.ru.md#текущие-ограничения).
Укажите версию форка, Windows, madVR и Java, издание и регион диска, действия,
ожидаемый и фактический результат. Уточните, использовались мышь или клавиатура.
Прикладывайте только нужный проверенный фрагмент журнала, убрав личные пути.
Не загружайте целую папку плеера, личный INI, сохранения или файлы диска.
